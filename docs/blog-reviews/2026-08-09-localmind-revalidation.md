## 공개 근거 범위

LocalMind에서 다음 결정 주제를 확인하고 현재 저장소와 교차 검증했다.

- SDD의 `goal → spec → plan → tasks → 구현 → self-review` 실행 흐름.
- `review.md`를 완료 증거 문서로 포함한 다섯 문서 체계.
- 사람은 방향 입력을 맡고 AI는 `tasks.md` 이후 구현과 self-review를 이어서 수행하는 역할 분담.
- 방향이 정해진 뒤 중간 사람 게이트를 최소화하는 원칙.
- SDD 착수 전 조사·벤치마킹과 작업 성격별 intake를 둘 수 있다는 경계.
- `tasks.md`를 AI 위임 계약으로 사용하는 기준.

비공개 note 경로, 개인 정보, 비밀 값, 비공개 저장소 URL과 원문은 이 공개 기록에 포함하지 않았다.

## 반영한 수정

1. 사람의 `goal.md`·`spec.md`·`plan.md` 방향 입력과 AI의 `tasks.md`·구현·self-review 범위를 명시했다.
2. 방향 결정 뒤 결과를 바꾸는 모호함만 사람에게 올리는 경계를 추가했다.
3. 다섯 문서의 참조 순서와 실제 실행 흐름을 구분했다.
4. 사전 조사·벤치마킹 및 작업 성격별 intake 경계를 추가했다.
5. `review.md`를 독립 self-review 결과와 완료 증거를 연결하는 문서로 보강했다.
