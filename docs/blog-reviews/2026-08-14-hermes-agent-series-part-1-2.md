## 최초 평가와 수정

최초 초안은 **수정 필요**였다. 개념과 명령의 목록은 있었지만 사용 이유, 적용 경계와 실패 시 진단 기준이 짧아 기술 정보 글보다 개인 메모처럼 읽혔다. 다음을 보강했다.

- 1편에 에이전트 실행 흐름, 여섯 구성 요소, ChatGPT OAuth의 역할, 세션·메모리·스킬 차이, 프로필과 sandbox의 경계를 추가했다.
- 2편에 설치 완료 기준, Apple Silicon 지원 조건, Desktop·CLI 선택, 비공식 Homebrew·PyPI 설치 경계, 실습 폴더 검증, launchd와 macOS 권한 범위를 추가했다.
- Apple Silicon은 Tier 1이고 Intel macOS는 지원되지 않는다는 공식 지원 조건을 설치 명령보다 앞에 배치했다.
- 실제 호스트명, 사용자명, 토큰, 사설 주소와 개인 절대경로를 제거하고 공개 가능한 `~` 상대 경로와 일반 예시만 사용했다.
- 정보·실습형 글을 억지로 1,000자 안에 줄이지 않도록 `articleType: guide`를 도입하고, 일반 글의 3~4분 계약은 그대로 유지했다.

## 독립 한결 재검토와 반영

독립 검토는 정확성, 핵심성, 설명 충분성, 시각화, 시리즈 독립성, 과장·AI 문체·보안을 승인했다. 다만 검토 시작 뒤 추가된 장문 가이드 정책을 반영하지 못해 3~4분 기준 초과를 지적했고, 2편에서는 선택적 게이트웨이의 완료 조건과 마지막 체크리스트 중복을 실제 수정 사항으로 찾았다.

- 2편의 완료 기준을 기본 설치 다섯 항목과 선택적 상주 한 항목으로 분리했다.
- 마지막 중복 체크리스트를 제거하고 상단 표를 유일한 완료 기준으로 남겼다.
- 업데이트 안내를 명령 블록에서 한 문단으로 압축했다.
- 분량은 사용자의 “메모처럼 줄이지 말고 독립적으로 따라갈 수 있게 설명한다”는 최신 요구와 현재 `articleType: guide` 정책에 따라 유지했다. 두 글 모두 가이드 상한 안에 있고 핵심·단계 제목·표·출처로 탐색할 수 있다.

## 공개·보안 검사

- 실제 사용자 홈 절대경로, 호스트명, 사설 IP, 이메일, 계정 ID, API 키, OAuth credential과 봇 토큰: 없음.
- `~/.hermes`, `~/.local`, `~/hermes-playground`는 제품 문서와 실습을 위한 비식별 상대 경로다.
- 원격 설치 스크립트는 공식 URL을 사용하며, 바로 실행하기 불편한 독자를 위해 다운로드 후 검토하는 대안도 함께 제시했다.
- `sudo`와 `--yolo`를 기본 경로로 권하지 않고, 위험 명령 승인과 최소 권한 원칙을 설명했다.
