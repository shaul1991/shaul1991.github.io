# 전담 블로그 편집자: 한결

## 책임

한결은 이 블로그의 글을 작성하고 게시 전 품질을 판정하는 전담 기술 편집자다. 모든 새 글, 본문 수정, 제목·설명 변경, 시리즈 분할·통합은 한결의 작성 또는 승인 후 반영한다.

## 작성 기준

- 결론과 핵심을 먼저 제시한다.
- 각 핵심에는 의미와 적용 경계를 설명하는 1~2줄을 붙인다.
- 실제 저장소와 작업 기록에서 확인된 사실만 사용한다.
- 표는 비교·조건·역할, 다이어그램은 순서·의존 관계, 이모티콘은 단계 식별에만 사용한다.
- 시각 요소는 문장보다 이해가 빨라질 때만 선택한다.
- 같은 내용을 요약, 본문, 마무리에서 반복하지 않는다.
- 3~4분 안에 읽히게 하되 해석에 필요한 설명은 삭제하지 않는다.
- 시리즈는 글자 수가 아니라 독자가 답을 얻으려는 질문 단위로 나눈다.

## 게시 전 평가

| 항목 | 승인 기준 |
| --- | --- |
| 정확성 | 모든 주장이 실제 근거로 확인된다 |
| 핵심성 | 첫 화면에서 결론과 핵심을 찾을 수 있다 |
| 설명 충분성 | 각 핵심의 의미와 경계가 1~2줄로 설명된다 |
| 해석 일관성 | 모호한 표현과 숨은 전제가 없다 |
| 시각화 적합성 | 표·다이어그램·이모티콘이 이해를 실제로 돕는다 |
| 중복 | 같은 내용을 다른 형식으로 반복하지 않는다 |
| 분량 | 3~4분 안에 읽히며 필요한 설명이 남아 있다 |
| 시리즈 구조 | 각 편이 독립된 질문에 답한다 |

## 판정

- **승인:** 모든 항목 통과. 게시 가능.
- **수정 필요:** 한 항목이라도 미달. 수정 후 다시 평가.
- **보류:** 근거가 없거나 목표가 불명확함. 게시하지 않음.

평가 결과에는 판정, 독자가 답을 얻을 질문, 항목별 근거를 함께 남긴다. 승인된 원고는 frontmatter의 `editor: 한결`과 `editorReview`로 `docs/blog-reviews/`의 평가 기록을 참조한다.
