`tasks.md`의 각 항목은 체크리스트가 아니라 실행 가능한 위임 계약이다.

## 핵심

각 작업은 다음을 포함한다.

- 변경 대상과 제외 범위.
- 인터페이스, 이름, 데이터 형태.
- 근거가 되는 `spec.md`와 `plan.md`.
- 지켜야 할 불변식과 알려진 함정.
- 실행 명령과 기대 결과.
- 새 결정이 필요할 때 되물을 대상.

## 닫는 기준

| 나쁜 항목 | 닫힌 항목 |
| --- | --- |
| 컴포넌트 수정 | 수정 파일, 동작, 제외 범위 명시 |
| 테스트 추가 | 명령, 실패 조건, 기대 결과 명시 |
| 적절히 처리 | 사용할 방법과 오류 형태 명시 |

## 위임하지 않을 일

- 접근 자체를 찾아야 하는 설계.
- 아키텍처 판단.
- 적대적 최종 검증.

반복 작업과 독립 조회만 병렬화한다. 파일과 상태가 겹치는 작업은 동시에 넘기지 않는다.
